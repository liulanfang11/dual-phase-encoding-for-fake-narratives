This repository contains the raw behavioral data, derived fMRI data, and analysis code used to generate the results reported in Figures 1–5 for the study “Encoding as True, Revising Later: Dual-Phase Processing for Narratives Labeled as Fake News.”

For further information, please contact the corresponding author: liulanfang21@bnu.edu.cn



The file “sub_group_ID” contains subject IDs corresponding to the fake-labeled and fact-labeled conditions, which are used in the data files for Figures 1–4.
